# 🚀 Ultimate CV Builder Pro v44

**Live Demo (GitHub Pages):** [Click Here to Build Your CV](https://naeemnajm.github.io/CV/)
**Live Demo (Vercel):** [Click Here to Build Your CV](https://ourcv.vercel.app/)

**Ultimate CV Builder Pro** is a fully dynamic, 100% client-side CV generator designed to help job seekers build professional, ATS-friendly, and modern resumes instantly. It features 21 premium templates, adaptive UI themes, real-time preview, multi-level dynamic sections, and a smart JSON data sync engine.

---

## 🎯 Motivation & Objective
Many talented and qualified job seekers fail to get interview calls simply because they lack a professional and standard CV. It is not possible for everyone to pay a professional designer to create one. My small initiative is primarily aimed at helping job seekers and reducing unemployment. Using this tool, anyone can create an international-standard CV absolutely for free, without needing any coding or design knowledge.

## ✨ Key Features
* **🎨 20 Premium Templates:** Choose from Minimalist Light, ATS-Classic, Modern, Glassmorphism, Cyberpunk, Neumorphism, and many more.
* **🌗 Adaptive UI Themes:** Toggle between Auto, Light, and Dark modes for the optimal editing experience.
* **⚡ 100% Client-Side & Secure:** No database is used. Your personal data never leaves your browser.
* **🧩 Multi-Level Dynamic Sections:** Add, remove, or rename any section, including new nested sub-sections (Sub-title + Content) for customized event tracking.
* **🔤 Premium Typography:** Integrated world-class UI fonts like 'Inter' and 'Plus Jakarta Sans' for a highly polished look.
* **📸 Live Face-Zoom Tool:** Upload your photo and easily adjust scale, X-axis, and Y-axis to fit perfectly.
* **💾 Smart Data Sync & 3D Modal:** Download your CV data as a `.json` file and import it later to restore everything with one click. A smart 3D animated modal elegantly explains the backup benefits right after generating your PDF.
* **📱 Responsive Design:** A dedicated mobile-friendly UI with bottom navigation for easy editing on smartphones.
* **📄 Direct PDF Export:** High-quality, properly scaled PDF generation using `html2pdf.js`.
* **💖 Support System:** An integrated floating button for users to support the project via local and international platforms.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and layout.
* **CSS3:** Advanced styling, CSS variables, Glassmorphism, and responsive media queries.
* **Vanilla JavaScript:** DOM manipulation, dynamic rendering, and JSON import/export handling.
* **Libraries:** [html2pdf.js](https://ekoopmans.github.io/html2pdf.js/) for client-side PDF generation.

## 💡 How to Use
My personal information is provided in the tool by default as a demo. You can easily customize it:
1. **Gather Data:** Prepare your personal, educational, and professional information.
2. **Use AI to Format:** Give your raw data to any AI Chatbot (ChatGPT/Gemini) and prompt it: *"Format my information beautifully, exactly following the structure of this CV."*
3. **Copy & Paste:** Paste the AI-formatted text into the edit panel on the left side of this tool.
4. **Customize:** Upload your photo, add/remove sections, and choose your favorite template from the top menu.
5. **Export:** Click **'Download PDF'**. Your CV will be generated instantly, followed by a smart prompt to download your data backup file (`.json`). Use the 'Import Data' button next time to load your data back!

## 💡 কীভাবে ব্যবহার করবেন?
এখানে আমার নিজের সিভির তথ্যগুলো ডিফল্টভাবে ডেমো হিসেবে দেওয়া আছে। খুব সহজেই আপনি এটি নিজের মতো করে সাজিয়ে নিতে পারবেন:
১. **তথ্য সংগ্রহ:** প্রথমে আপনার সমস্ত ব্যক্তিগত, শিক্ষাগত ও পেশাগত তথ্যগুলো গুছিয়ে নিন।
২. **এআই (AI) এর সাহায্য নিন:** যেকোনো এআই চ্যাটবটকে (Gemini বা ChatGPT) আপনার তথ্যগুলো দিন এবং নির্দেশ দিন— *"আমার এই তথ্যগুলো ঠিক এই ডেমো সিভির ফরমেটে সুন্দর করে সাজিয়ে দাও।"*
৩. **কপি ও পেস্ট:** চ্যাটবট আপনাকে চমৎকারভাবে টেক্সটগুলো সাজিয়ে দেবে। আপনি শুধু সেখান থেকে কপি করে এই টুলের বাম দিকের প্যানেলে পেস্ট করে দিন। 
৪. **কাস্টমাইজ:** নিজের ছবি আপলোড করুন এবং ওপরের মেনু থেকে আপনার পছন্দের টেমপ্লেট সিলেক্ট করুন।
৫. **ডাউনলোড:** সবশেষে **'Download PDF'** বাটনে ক্লিক করুন। আপনার সিভি জেনারেট হওয়ার সাথে সাথেই ডাটা ব্যাকআপ নেওয়ার জন্য একটি অপশন আসবে, যা অটোমেটিক সেভ করে রাখতে পারবেন।
